# PatternFoundry v0.1.3 (draft release notes)

Suggested version: **v0.1.3** (changes since v0.1.2). Draft for the owner to approve; this PR makes no version bump, tag or release.

Maturity: **first release.**

## New
- **Placed designs know which app edits them** (`piece.placementLink`), so a design placed on a pattern piece can be sent back to the right app.

## Fixed
- Size charts that name the same size or measurement twice are refused with a clear message instead of being half-read.
- A size range and its grade rules are checked when read from a file; a measurement set is checked when read from a document.
- A piece read from a file keeps its placement limits.
- Reading DXF-AAMA files with many block inserts is faster and more reliable.
- A pasted group is counted correctly in the regression test.
- Moved off a version of a web-assembly library that had been withdrawn, and updated several libraries to their latest patch and minor versions.
