# PatternFoundry v0.1.2

Maturity: **first release.**

Changes since v0.1.0:

## New
- **Start a Pattern from measurements**: a new user is led from their measurements to a first block
  (Draft … Block). Ticked measurements are kept as "Me" when no name is given, and the status bar
  says so if they could not be kept.
- **Staging switch for the web app** (`?services=staging`), for testing against the staging services.
- README Download section; web app description and favicon.

## Changed
- The Foundry Account is the only way to sign in and pay for AI; the "use my own API key" option is gone.
- Customer-facing text and links now say StitchFoundry / Foundry; repo links, the Pages address and
  the update check point at StitchFoundry.
- Windows installer finish-page text is one string (fixes the v0.1.1 MSI build).

## Fixed
- Saving a measurement set again under another letter case replaces the old file; deleting a set
  removes every case variant.
- Paste in Front / Paste in Back never lands inside a compound path.
- Opening a DXF-AAMA piece digitised as many short edges no longer stalls (80 000 points: 46 s to under 1 s).
- Very long measurement formulas no longer overflow the stack.
- A size chart's "not a number" error names the right line.
- The Foundry service's own words are shown for an unconfirmed email.

## Under the hood
- Pattern placement model in pf-core (groundwork for placing designs on pieces).
- Security and dependency updates (tokio, yoke-derive, async-executor, hayro-ccitt, vello 0.3 renderer port).
